## 偏离与未决

- **二进制漂移判据改为 GNU build-id**：实测同源码、同输出路径连续两次构建的整文件 SHA-256 不同（仅 6 字节随机临时标记差异），build-id 恒定。原计划的"SHA-256 相等"不可用。
- **`index_by` 不可随手改**：把 `sections.thickness` 的 `index_by` 改成 `materials[].name` 曾使四条状态探针全部 FAIL，因为 `index_by` 会写进规范化快照，与 M2-03 冻结证据冲突。已撤回并在映射表 note 中写明禁止。结论：映射表中参与快照内容的键（`dtype`/`index_by`/`shape`/字段集合）改动会作废冻结证据，只有 `owner`/`note`/`legacy_only` 可自由修正。
- **`solver.symmetric`**：映射表 `dtype` 保持 `i32`（那是 legacy 线格式类型，驱动 state dump 且写入冻结基线），类型层用 `opt_logical` 并带 `@repr: bool from i32` 标记，取反在 bridge 完成。
- `steps[0].load.gravity.amplitude` 与 `steps[0].output.stress_averaging` 的 owner 路径无集合括号却带 `ngroup` 形状，本阶段声明为可分配向量；若 M5 需要子集合，需同时改 owner 路径。
- 复核人未指定，阶段停在 IN_REVIEW。
