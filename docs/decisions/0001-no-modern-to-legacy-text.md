# ADR-0001：现代输入不得编译为旧文本再进入 YL

- 状态：接受
- 日期：2026-09-07

## 背景

hstarpre 已经验证了“高层输入生成旧 deck”的实际困难：最终仍要满足位置敏感、分支相关的
旧 reader 协议，一个小错误即可导致错位、半初始化或计算崩溃。

## 决策

现代输入直接构建 `ProblemState`。旧 deck 只由 Legacy Adapter 读取。modern 路径不得为了
复用原 reader 而生成 `.glb/.man/.loa` 等中间文件。

## 后果

- 初期需要修改 YL 初始化边界，工作量高于纯外部生成器；
- 一旦能力迁移完成，新路径不再承担旧文本脆弱性；
- 可直接在内存对象上验证尺寸、引用、单位和物理组合；
- 旧格式兼容和现代输入可以独立演进。
