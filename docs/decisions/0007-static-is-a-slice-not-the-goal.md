# ADR-0007：静力是第一个切片，不是项目目标；后续按功能域展开

- 状态：接受（负责人 Huijun，2026-09-10）
- 相关：`docs/00-project-charter.md`（使命与汇报口径已同步改写）、
  `docs/02-migration-plan.md`（M6～M9 即功能域展开）、ADR-0003（CAE 对象模型与 SI）

## 背景

到 2026-09-10，M0～M3 已交付、M4-01 待签收，全部工作都落在**二维静力**这一条路径上。
项目文档与历次汇报把目标表述成「输入系统迁移」，实践中进一步收窄成「静力迁移」。

负责人指出这个表述是错的，并给出订正：**YL 的功能远不止静力；静力只是第一个迁移切片，
它的作用是验证迁移方法与验收体系是否成立。**

这不是范围扩大，而是**把一直隐含在计划里的东西写到目标里**——`02-migration-plan.md`
的 M6（静力能力扩展）、M7（模态与动力）、M8（温度/渗流/多场）、M9（长尾）本就存在。
错的是章程的使命段与汇报口径，它们让「静力做完」读起来像终点。

## 决策

**总体目标订正为：以输入体系现代化为主线，逐步把 legacy YL 求解器迁移成结构清晰、
可校验、可扩展、且有回归证据保障的现代程序结构。**

配套五条：

1. **静力先走通，但不得把静力完成当作项目结束。** 规范表述是
   「静力切片完成，迁移框架成立，然后按功能域扩展」。
2. **后续逐步覆盖**动力、材料、边界条件、施工/加载过程、非线性、接触及其余现有输入功能。
3. **每个功能域都要建立五件套**：旧输入字段 → 语义 → 内部数据结构 → 新 schema → 回归证据。
   缺任一段，该域不算迁移完成。
4. **新输入体系尽量统一设计**，避免各功能域各自形成孤立格式；同形概念复用既有词汇，
   判断标准仍是 ADR-0003。
5. **自主研究服务于迁移**：深入内部复杂行为的前提是它影响输入语义、迁移正确性、
   兼容性或后续结构设计四者之一；四者都不沾的，登记备查，不展开。

**汇报口径同时订正为六问**（章程「汇报口径」节）：覆盖到哪个域、语义是否摸清、
新格式是否可表达、新旧是否计算等价、下一步哪个域、是否有需负责人裁定的架构级问题。

## 这条订正**不**改变什么

明确写下来，以免被当成重新开工的许可：

- **不改变 M0～M4 已有的任何证据与判据。** M2/M3 按 ADR-0005 继续走完签收，
  M4-01 已交付的矩阵与结论不动。
- **不改变「证据不可外推」**。方法可复用，证据不可复用：静力域的等价证据
  对动力域没有任何效力。
- **不是提前立项 M6～M9。** 它们的出口条件不变，仍需前一阶段过门后才开始生产迁移。
- **不放宽 `docs/07-acceptance-and-release.md` SECTION 02 的能力声明限制。**
