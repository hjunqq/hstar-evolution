# ADR-0006：冻结状态基线的验收口径是「字段值级可复现」，不是字节级同一

- 状态：接受（负责人 Huijun，2026-09-10，随 M2/M3 有条件签收一并裁定）
- 相关：R26（指纹跨 profile / 跨映射表版本不可比）、M2 验收矩阵判据 16 与 17、
  ADR-0005（M2/M3 一并签收）

## 背景

`cases/golden/*/reference/state/` 是 M2-03 冻结的状态基线，四十个文件一例。M2 验收
矩阵复核时发现两件互相咬合的事：

1. **判据 16 已失效**：`M2-03-state-evidence.md` §4 记下的两个指纹值今天都不复现
   （`547e53a8fc6c` → `95f9ed237500`、`7c2edf39a342` → `42f345980448`）。
2. **判据 17 的字面表述今天不成立**：把冻结树与一次新鲜运行逐文件比较，**40 个文件
   逐字节全不相同**。

根因是同一个，而且是设计使然：每个快照 json 都携带 `map_sha256` 溯源键，映射表一改，
四十个文件的字节就全变。映射表自 M2-03 以来被 M3/M4 正当地改过多次。

关键的第二个事实是：**剥去 `map_sha256` 及由它派生的四个 `.sha256` 摘要与
`fingerprint.json` 的三个键之后，三个检查点的每一个字段值完全相同。**

第三个事实决定了这不是回归：**字节级同一性从未被任何门禁强制过。** 读这份基线的四处
消费者——`yl_state_probe.py run`、L3-a `yl_adapter_fidelity`、L3-b
`yl_adapter_bridge_test`、`yl_map_selfcheck.py`——**比较的全部是字段值**。
`yl_state_probe.py verify` 报 PASS 也不是缺陷：它自述是
`re-hash the frozen tree against frozen.json`，即**防篡改**检查，从未声称「新运行可复现」。

## 决策

**冻结状态基线的验收口径修订为：字段值级可复现。**

具体地：

1. **判据 17 的正式表述**改为——「冻结基线在当前源码树上仍然成立」意为：一次新鲜的
   dump-on 运行，经 `yl_state.py normalize` 后，其**每一个字段值**与冻结基线一致，
   由**比较器**（`yl_state_diff.py`，含映射表登记的容差）判定。**不要求**、也**不追求**
   携带 `map_sha256` 的快照文件字节级同一。
2. **判据 16 撤销**。「M2-03 当时记下的那两个指纹值今天仍复现」不再是判据——它是一个
   随映射表版本变化的量，把它写成验收判据是**把版本号当成内容判据**。指纹保留其真实
   用途：**同一二进制、同一映射表版本内**的重复运行判据（S01）。
3. **provenance hash 的可追溯性保留，且是这次修订的对价。** `map_sha256` 继续写进每个
   快照，`frozen.json` 继续记录冻结时的完整摘要与来源。它的意义随之明确：指纹不同
   **回答的是「这两份快照是不是同一张映射表在同一个二进制上产生的」**，而不是
   「这两份快照的内容是否等价」。后者只由比较器回答。
4. **`yl_state_probe.py verify` 的定位写死为防篡改**，不得被引用为复现证据。

## 这个口径由什么强制

不新建门禁。值级可复现已经被现有门禁**顺带但真实地**强制：`yl_state_probe.py run` 的每一条
S03 探针，都要求扰动运行相对冻结基线**恰好出现映射表预测的那一个字段的差异、其余全部
PASS**——「其余全部 PASS」就是值级可复现，逐次、逐字段。

**如实记录其限度**：这个保证是**顺带的**，不是**指名的**。没有一条判据叫「基线仍可复现」；
它是四条探针的副产品。若将来需要指名的形式，路径已经写好：给 `yl_state_probe.py` 加一条
`reverify`——跑一次新鲜 dump-on 运行，用**比较器**（不是 sha256）对冻结基线判定。
本次不做，理由是收益重复而非无必要。

## 被拒绝的方案

- **把 `map_sha256` 移出被摘要的字节**（使指纹只覆盖字段值）。这样指纹会成为纯内容判据，
  判据 16 也就能复现。拒绝的理由：会**丢掉溯源**——从此无法从一份快照看出它由哪张映射表
  产生，而这正是本次能迅速定位根因的那个键。**用可追溯性换一个判据的字面成立，不划算。**
- **重新冻结基线**，让记录值与当前映射表一致。拒绝：冻结是一次性的、fail-closed 的
  （`yl_state_probe.py freeze` 无 `--force`，见其模块头），而且重新冻结会把「基线是独立于
  当前实现的证据」这一性质本身消耗掉。**基线的价值来自它不跟着实现走。**

## 影响

- M2 验收矩阵判据 17 由「独立证据支撑（值层）」升为**无保留的独立证据支撑**（口径与被测
  属性现在一致）；判据 16 撤销，不再计入判据总数。
- R26 的处置段增加本 ADR 的指向；风险本身仍 OPEN（现象仍在，只是不再被误读为缺陷）。
- 任何后续文档不得再把「指纹相同」写成跨构建或跨映射表版本的等价证据。
