# 测试规格

本文是测试实施与验收契约，列出的测试 ID 尚不表示有对应实现。测试报告必须分别记录
`PASS / FAIL / BLOCKED / NOT_RUN / NOT_APPLICABLE`；必需测试只有 PASS 才允许放行。
NOT_APPLICABLE 必须有该能力不消费此分支的依据和复核记录。

## 运行环境与证据

每次运行记录源码提交及本地补丁哈希、二进制 SHA-256、构建日志、编译器/链接参数、
库版本、OS/架构、线程数、输入哈希、模式、随机种子（如有）、起止时间、超时上限、退出码、
标准输出/错误、结果及比较器版本。接受证据必须来自干净检出；脏工作区运行仅供诊断。

所有测试在独立运行目录执行。先检查输入哈希，再运行，再次确认 golden 哈希不变。
不能默认运行目录已有合法输出；旧输出必须不可能被本次比较器误用。基线保存必要的结构化结果，
完整日志和大结果可放独立证据存储，但必须有地址、哈希及保留策略；文件不可取得则该证据无效。

## 负向测试的最低集合

M1 必须覆盖：必需文件缺失、记录中途 EOF、整数填字符、数量为负、超大数量、重复实体 ID、
连接引用不存在节点、组引用不存在材料、荷载引用不存在曲线。用小夹具测试超限，不能真的申请
巨量内存。故障注入放在候选初始化边界，不能改变参考程序来掩盖其行为。

M3 增加：显式空约束、默认值来源丢失、失败后重新加载、分配失败、所有权转移失败前中止。
M5 增加：未知字段、单位不符、未知网格类型、未知分析类型、模型文件缺失、无边界选中、
非唯一名称、0 节点集合、禁止的动力激励组合请求。未开放动力时返回“不支持”，不得运行它。

退出协议建议冻结为：0 成功；2 输入错误；3 能力不支持；4 初始化失败；5 求解失败；
6 内部错误。运行器超时使用独立状态 TIMEOUT，不能把它归入某个正常求解器退出码。
错误结果至少有 `code/stage/object/field/source/message`，legacy 来源使用 reader 与记录定位，
现代输入来源使用文件行列（没有准确列号就明确缺失，不能编造）。

## 数值比较与容差登记

所有数组先检查字段集合、实体 ID、时间/阶段 ID、长度、shape、有限性，再比较值。
不得以 zip 截断、缺字段默认零、空数组全通过或仅比较最大值实现验收。

逐分量判据：`abs(actual - reference) <= atol + rtol * abs(reference)`。
每种物理量单独登记单位、atol、rtol 和理由；接近零的量依赖有量纲 atol，不能只用相对误差。
全场还记录最大绝对差和最大归一化差的位置；范数作为补充，不能代替逐分量检查。

- 输入原值、名称、数量、引用和离散选择：精确比较；格式变换后的数值按明确规范归一化。
- 派生浮点状态：以同环境重复运行噪声和运算顺序为依据定容差；不要求跨编译器哈希相等。
- 位移/应力/反力：在查看候选结果前，以参考尺度、求解精度和重复波动确定绝对/相对容差。
- 非线性：检查终态及关键加载点、收敛状态、残差；如允许迭代次数变化，必须预先给范围。
- 模态：处理符号和重根子空间不唯一性；不能直接逐值比较未经对齐的特征向量。

容差未定、单位未核实或观察量缺失时结果为 BLOCKED。不得用一个通用 `1e-6` 覆盖所有量，
不得看到差异后放宽容差并直接验收。容差改变需要独立任务及新旧规则下的报告。

## 物理判据的选择

首条静力路径至少具备：常应变 patch test、外力与约束反力平衡、一个独立弹性基准。
Lamé 必须先确定内外半径、压力、平面应力/应变或轴对称假设、厚度及应力取样点；不满足解析
模型的现存 deck 只能作回归例，应新增匹配解析模型的 probe。Cook 不能当作通用精确解析解。

后续能力在开工前登记以下专项判据的适用条件、公式来源和容差：

| 能力 | 独立证据要求 |
|---|---|
| 塑性/损伤 | 单元级加载卸载路径、屈服/损伤演化和材料耗散；确认材料约定 |
| 模态 | 解析频率或可靠参考、残差、质量正交性；检查质量矩阵约定 |
| 固定边界动力 | 单自由度解、步长收敛、零激励保持；区分绝对和相对响应 |
| VIE/FSI | 匹配入射波约定的反射测量、能量输入/存储/耗散/辐射核算，先登记适用条件 |
| 温度/渗流 | 解析小问题、通量平衡、时间/网格收敛；极值原理只用于满足其假设的模型 |
| 施工/重启 | 激活与初始状态约定、分段/连续运行的一致性及重启完整性 |

迁移保持旧行为与证明物理正确分开报告。旧行为有 bug 时保留参考证据，新增单独修复变更，
不得为了“数值等价”继续把已知物理错误标为 production。

## 自动化频率

PR：构建、受影响单测、比较器反例、小型正/负例和已开放能力冒烟。
夜间：全部已开放能力回归、debug 运行、重复运行、跨阶段测试。
阶段验收/发布：干净检出全量必需矩阵、独立物理报告、平台/线程变体和回退演练。
只有实际部署支持的构建组合才标支持；第三方库检查盲区单列，不能写“无内存问题”。

性能在 M0 登记墙钟和峰值内存，M5 才建立预算；在固定机器和线程上重复测量。
超预算必须调查，数值错误不得用性能收益豁免。预算值由 M0 数据决定，当前不宣称已通过。
