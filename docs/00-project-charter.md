# 项目章程

## 使命

**以输入体系现代化为主线，逐步把 legacy YL 求解器迁移成结构清晰、可校验、可扩展、
且有回归证据保障的现代程序结构。**

输入体系是主线，不是全部目标：它是抓手，因为几乎每种计算能力都以输入语义为入口，
沿着输入往里走可以在不一次性重写计算核心的前提下逐域推进。具体地，把
“位置敏感、出错即崩溃”的输入系统迁移为：

- 简洁且使用物理概念命名的输入；
- 可在计算前完整检查的强类型问题状态；
- 明确区分输入错误、能力不支持和求解失败；
- 新旧路径可在内存状态、数值结果和物理判据上比较；
- 每一步均可回退到固定的 YL 基线。

### 静力切片的地位（2026-09-10 由负责人订正）

**静力不是项目的终点，是第一个切片。** 它的真正产物有两个：一条走通的路径，
**以及一套可复制的迁移方法与验收体系**。后续每个功能域按同一方法展开。

因此明确禁止两种表述：

- **不得把「静力迁移完成」写成「项目完成」。** 正确的表述是
  **「静力切片完成，迁移框架成立，然后按功能域扩展」**。
- **不得把某个功能域的证据推广到未做过的功能域。** 迁移方法可复用，
  证据不可外推——这与本项目反复出现的「覆盖面不足 ≠ 结论可疑，但也 ≠ 已覆盖」是同一条纪律。

### 功能域展开方法（每个域的五件套）

后续要逐步覆盖**动力、材料、边界条件、施工/加载过程、非线性、接触，以及其余现有输入功能**。
每个功能域都必须建立完整的五段链条，缺一段即不算该域迁移完成：

1. **旧输入字段**——该域在 legacy deck 中占用的记录与字段，逐个登记，不留“其余同上”；
2. **语义**——每个字段实际决定什么；哪些是开关、哪些是哨兵、哪些是与其他字段的**关系**
   而非常量（`stab_matde=99999` 是禁用哨兵这类教训属于此段）；
3. **内部数据结构**——该语义在 `ProblemState` / `RuntimeState` 中的归属与所有权；
4. **新 schema**——现代输入中如何表达；
5. **回归证据**——新旧路径的状态等价与数值等价，含阴性对照。

### 新输入体系的统一性要求

**新输入体系应尽量统一设计，避免不同功能域各自形成孤立格式。** 一个域引入的新概念，
若与已有域的概念同形，必须复用既有词汇与结构，而不是另起一套。
判断标准写在 ADR-0003（CAE 对象模型 + SI 单位）：**先问“这在标准 CAE 语汇里叫什么”，
再问“YL 怎么叫它”**，不允许第三种自造分类。

### 自主研究的边界

**允许自主研究，但研究服务于迁移，不是无限制探索。** 深入程序内部复杂行为的前提是：
它会影响**输入语义、迁移正确性、兼容性或后续结构设计**四者之一。
四者都不沾的内部行为，登记备查即可，不展开。

## 汇报口径

面向负责人的汇报以下列六问为准，**先答这六问，再谈实现细节**：

1. **当前覆盖到哪个功能域**；
2. **该域的输入语义是否已经摸清**；
3. **新格式是否已经可表达**；
4. **新旧输入是否计算等价**；
5. **下一步迁移哪个功能域**；
6. **是否有需要负责人裁定的架构级问题**。

实施进度（Implementation Progress）与验收进度（Accepted Progress）**始终分开报**，
不得合并；「产物存在」不等于「已签收」。

## 范围

项目包含：

- YL 输入读取和初始化的加固；
- `ProblemState`、`RuntimeState` 和受控提交接口；
- legacy 与 modern 两种输入适配器；
- 简洁输入格式、单位、引用和跨字段规则；
- 状态摘要、回归算例、故障探针和物理验证；
- 为迁移所必需的求解器模块边界整理。

项目暂不包含：

- 为了代码美观而全面重写单元、材料和求解算法；
- 未经基准支撑的数值算法替换；
- 自动修正含糊或不完整的工程输入；
- 通过生成旧 deck 来实现现代输入；
- 同时维护两个行为不同却都叫 YL 的生产求解器。

## 成功标准

普通二维静力算例最终应能用约 30～50 行输入表达；复杂能力可以更长，但只出现该能力真正
需要的字段。所有现代输入必须在进入组装前得到确定结果：`READY`、`INVALID_INPUT` 或
`UNSUPPORTED_CAPABILITY`，不得以进程崩溃代表输入错误。

生产能力必须同时满足：

1. 输入 schema 通过；
2. 语义和单位规则通过；
3. 初始化状态确定且可摘要；
4. 与基线数值结果在规定容差内一致；
5. 至少一个独立物理判据通过。

## 非功能性约束

- 基线可重复：编译器、依赖、源码提交和算例哈希可追溯。
- 错误可定位：至少包含阶段、对象、字段以及来源位置。
- 初始化可中止：失败时不留下半初始化全局状态。
- 能力显式：所有开放组合由白名单声明。
- 变更可审计：默认值、派生值和单位换算进入构建清单。
